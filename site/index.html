A local-first model router for OpenCode.

Every task is routed to local (Ollama) or cloud automatically. No manual /models switching. When the model changes mid-session, Arbiter hands off exactly the context the next model needs.

~/project · opencode
how it works

One proxy between OpenCode and every model.

OpenCode points its provider baseUrl at Arbiter. Arbiter classifies each task, resolves a concrete model against a live catalog, and forwards it using its own credentials.

   OpenCode  ──baseUrl──►  Arbiter Server  ──►  Ollama  (local, free)
   + Notary plugin                  │           └──►  Anthropic / OpenAI / …  (cloud)
                                    │
                     Triage   classify difficulty → resolve tier → pick model
                     Ferry    reshape context when the model changes
                     Registry models.dev · OpenRouter benchmarks · Ollama tags
design

Four parts, one clean boundary.

All routing lives in the server. The plugin is UI and logging only. It never calls a model.

Triage

Classify, then resolve.

A trained PyTorch classifier labels each task easy / medium / hard. A deterministic resolver maps that to a tier and a concrete model. Benchmark score first, cost and capability as fallbacks.

pretrained · fine-tunes locally
Ferry

Context that survives the switch.

When the model changes mid-session, Ferry decides how much history travels with the task, scaled to the tier, never the full dump or a blind compression.

reactive · never picks a model
Registry

A live model catalog.

Merges models.dev pricing + context windows, OpenRouter benchmark scores, and your actual local Ollama tags, so tiers resolve against real data, not a stale list.

3 sources · identity-matched
Notary

You stay in the loop.

The OpenCode plugin shows each routing decision as an accept/override menu and logs corrections that fine-tune the classifier on your machine over time.

/train-mode · local only
local-simple

Minimal payload: the task plus the files it directly touches.

cloud-mid

A structured handoff summary: goal, decisions, work done, remaining, constraints.

cloud-heavy

Full raw history, uncompressed. The top tier keeps every detail.

install

Up and running in three commands.

Requires Node 18+, Python 3.11+ on your PATH, and (optionally) Ollama for local models.

# install the CLI + OpenCode plugin
$ npm install -g opencode-arbiter

# download the server, build a venv, patch OpenCode config
$ arbiter setup

# start the router on 127.0.0.1:4317
$ arbiter start

Manage it with arbiter status and arbiter stop. Toggle the approval menu inside OpenCode with /train-mode.
